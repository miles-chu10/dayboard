A daily workspace

See the day. Get it done.

DayBoard brings the sources you already use into one desktop view, so the next useful action is easier to find.

01 / Agenda

A single view of today

See Google Calendar events alongside Google Tasks and Apple Reminders. Choose your sources and move between today and the week ahead.

02 / Connected work

Mail and calendar nearby

Read Gmail, check upcoming meetings, and work with tasks and reminders without hopping between windows.

03 / Your choice

Optional AI and MCP

Use supported AI providers for briefs, drafts, and assistance, or leave AI off. An optional local MCP server can connect desktop clients.

Clear data boundaries

Your accounts stay yours.

The app keeps local settings and history on your Mac. Using Google services sends requests to Google; Apple Reminders uses macOS access. Optional AI sends selected context to your chosen provider when you use it.
