Get the DayBoard beta.

The latest beta is DayBoard 1.3.0 beta 17. Every feature is free during the beta. The app is signed with an Apple Developer ID, notarized by Apple, and updates itself.

What you need

  • A Mac with Apple silicon (M1 or later) running macOS 14 Sonoma or later.
  • A Google account for Google Calendar, Google Tasks and Gmail, if you use them. Google sign-in may be limited to invited accounts.
  • For the optional AI features: Claude Code, the Codex app or CLI, or an API key from your AI provider.

Install

First-install limitation: the app is notarized, but beta 17's DMG container itself is not yet notarized and may be blocked by macOS. If that happens, stop and contact support.

  1. Download the .dmg, open it and drag DayBoard into your Applications folder. If an older beta is there, replace it. Your DayBoard data stays in place.
  2. Open DayBoard from Applications. If macOS asks whether to open an app downloaded from the internet, click Open.
  3. Turn on your sources in Settings → Sources. The install guide covers Google sign-in.

Already on beta 12 or later? DayBoard installs new betas when you restart, so you don't need to download it again.

New in beta 17

Start at Home, send and snooze mail, ask the Assistant beside any view, and keep Notes. The command menu, calendar peek, tabs and sidebar settings help you move around. Read the guide for the new controls and shortcuts.

Check the download

Only install DayBoard from this page or the official GitHub release. The release lists SHA-256 checksums for every file in SHA256SUMS.txt. If macOS ever says it can't check DayBoard for malicious software, don't open that copy.
