Getting started

DayBoard guide

A short introduction while the public Mac build is being prepared.

Start with your Agenda

DayBoard is designed to bring Google Calendar, Google Tasks, and Apple Reminders into one Agenda. Source controls let you focus the view. Gmail has its own inbox view.

Connect the sources you want

Google Tasks, Gmail, and Google Calendar require Google sign-in and the permissions for the sources you enable. Apple Reminders requires macOS permission. Connected services continue to store and process their own data under their own terms.

Use AI only when useful

AI features are optional. Depending on the provider you choose, DayBoard may use a signed-in desktop CLI or an API key. AI requests send the context needed for that feature to the selected provider. Review the provider's terms and privacy practices before enabling it.

Connect an MCP client if you choose

DayBoard can run a local MCP server while the app is open. It is optional and off by default. Access requires a key, and changes through MCP must be enabled separately in settings.

Where your data goes

DayBoard saves app settings and certain history locally on your Mac. Syncing with Google sends requests to Google's services. Apple Reminders access uses macOS permissions. AI features send selected context to the provider you configure. The exact permissions and final release privacy notice will be documented before a public download is offered.
