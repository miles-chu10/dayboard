Common questions about the app and its upcoming official Mac build.

Frequently asked questions

Can I download DayBoard now?

The public official build is still being prepared. The download page will carry the verified installer link when it is ready.

Do I need all four connected services?

No. The intended workflow lets you enable the sources you use. Google sources require Google sign-in, and Apple Reminders requires macOS permission.

Does DayBoard require an AI account?

No. AI is optional. If you enable it, you choose a supported provider, and relevant context is sent to that provider for each request.

Is the source really open?

The planned public source license is GPL-3.0-only. See the license explanation and the source repository.

Why charge for an official build?

Preparing and maintaining a convenient Mac download takes work. The source license lets you build from the GPL code yourself.

How will I activate a purchase?

The planned checkout opens Stripe's payment page. After payment, return to the DayBoard receipt page to copy or download your license key. Paste it into Settings → License in the Mac app. Keep a private copy of the key for reinstalling or moving to another Mac.

Report a problem

After the public source repository opens, use GitHub Issues for reproducible bugs and documentation problems. Please remove personal data, account tokens, and private messages before posting.

For now, the guide explains the intended source and data behavior. A dedicated purchase support channel will be listed when checkout opens.
