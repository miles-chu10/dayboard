# DayBoard 1.2.5

- A clearer selected-day or date-range heading, with years shown when needed.
- Day and Next 7 days controls, date arrows around Today, and filters that wrap within narrower windows.
- A quieter sidebar with primary navigation separated from AI tools, live date summaries, and clearer source loading and unavailable states.
- Open New Item from the File menu or with Command+N; repeated presses keep the current dialog and typed text.
- Existing theme, density, keyboard navigation, account settings and Glaze AI options remain available.
- Security updates for built-in components: the connector used for MCP servers is updated, and DayBoard's own MCP servers now refuse oversized or excessively nested requests before processing them.

Google access remains subject to the existing OAuth test audience.
