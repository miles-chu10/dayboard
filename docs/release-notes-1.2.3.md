# DayBoard 1.2.3

- Fixed: Changes made while Google was still signing in or out (including from MCP clients) could go through mid-change. DayBoard now waits for the account change to finish, and quitting waits for it too.
- Improved: The Orange and Yellow accents are darker in light mode, so checkboxes, selected tabs and today's date stand out clearly, with dark labels.
- Improved: VoiceOver now reads a name for every field in the edit dialog.
- Fixed: Demo mode no longer shows your saved API keys or which AI apps are installed.
